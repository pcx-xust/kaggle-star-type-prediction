# 探索性数据分析报告

## 1.数据集概况

本项目的目标是根据天体观测特征预测其所属类别。训练数据包含数值型观测变量和分类型特征变量，其中目标变量为天体类别，主要包括GALAXY、QSO和STAR三类。测试集不包含目标变量，需要利用训练集建立分类模型，并对测试集样本生成预测结果。

本阶段探索性数据分析主要围绕以下几个问题展开：

1.训练集类别分布是否均衡；
2.不同类别在数值变量上的分布是否存在明显差异；
3.哪些变量可能对分类任务具有较强判别能力；
4.后续建模时应采用哪些评价指标和特征处理策略。

---

## 2.变量说明

| 变量类型 | 字段                | 含义                 |
| ---- | ----------------- | ------------------ |
| 数值变量 | alpha、delta       | 天体坐标变量             |
| 数值变量 | u、g、r、i、z         | 不同波段的亮度/星等观测变量     |
| 数值变量 | redshift          | 红移变量               |
| 分类变量 | spectral_type     | 光谱类型，作为分类特征使用      |
| 分类变量 | galaxy_population | 星系/天体族群类别，作为分类特征使用 |

其中，alpha和delta主要表示天体在空间中的观测位置；u、g、r、i、z表示不同波段下的光度或星等信息；redshift表示红移信息，通常与天体距离、运动状态及物理属性有关。spectral_type和galaxy_population属于分类变量，需要在后续建模前进行适当编码。

---

## 3.目标变量分布

从目标变量分布结果看，训练集存在明显的类别不均衡问题。GALAXY样本数量最多，占比约65.38%；QSO样本占比约20.29%；STAR样本占比约14.33%。

| 类别     |     占比 |
| ------ | -----: |
| GALAXY | 65.38% |
| QSO    | 20.29% |
| STAR   | 14.33% |

这一结果说明，如果模型仅以accuracy作为评价指标，可能会倾向于预测多数类GALAXY，从而高估整体预测效果。例如，一个极端模型即使把全部样本都预测为GALAXY，也能获得较高的accuracy，但它对STAR和QSO的识别能力实际上很差。

因此，后续模型评估不能只依赖accuracy，还应结合balanced accuracy、macro F1-score、classification report和confusion matrix进行综合评价，尤其要关注少数类STAR和QSO的precision、recall和F1-score。

---

## 4.数值变量分布分析

从数值变量的单变量分布结果看，不同变量的尺度、偏态程度和取值范围存在一定差异。u、g、r、i、z等光度变量整体呈现较集中的分布，但部分变量存在尾部延伸现象；redshift变量的分布差异较明显，且存在一定极端值；alpha和delta作为坐标变量，取值范围较宽，分布主要反映天体观测位置。

这些结果说明，在后续建模时，不同变量可能对模型产生不同影响。对于树模型而言，变量尺度差异通常影响较小；但如果后续使用Logistic Regression、SVM、KNN等对尺度敏感的模型，则需要考虑标准化或归一化处理。

---

## 5.特征与目标变量关系分析

通过对数值变量按目标类别进行分组描述统计，可以进一步观察不同类别在各特征上的差异。

### 5.1redshift具有较强区分能力

redshift在GALAXY、QSO和STAR三类之间表现出明显差异。整体来看，STAR的redshift接近0，GALAXY处于中等水平，而QSO的redshift明显更高。三类样本在redshift上的分布呈现较清晰的梯度关系。

这说明redshift很可能是后续分类模型中的重要判别特征。尤其是区分QSO与其他类别时，redshift可能具有较强作用。

不过，redshift并不能单独完成全部分类任务。一方面，不同类别之间仍然存在一定重叠；另一方面，部分样本存在较大的极端值。因此，后续模型仍需要综合利用redshift、光度变量和分类特征，而不能简单依赖单一阈值进行分类。

### 5.2u、g、r、i、z光度变量具有明显类别差异

u、g、r、i、z等不同波段的观测变量在不同类别之间也存在明显差异。STAR在部分波段上的数值整体较低，QSO在r、i、z等波段上的数值整体偏高，GALAXY则表现出介于不同类别之间或具有自身特征的分布形态。

这说明光度变量对天体类别预测具有较强信息含量。由于天体分类往往不仅取决于单个波段的取值，还与不同波段之间的相对差异有关，因此后续可以进一步构造颜色指数特征，例如：

* u_g=u-g
* g_r=g-r
* r_i=r-i
* i_z=i-z

这些颜色指数能够反映不同波段之间的相对变化，可能比单个原始波段变量更有效地刻画天体光谱特征。

### 5.3alpha和delta单变量区分能力相对有限

alpha和delta作为天体坐标变量，在不同类别之间的均值存在一定差异，但类内波动较大，三类分布重叠明显。从单变量角度看，它们的类别区分能力弱于redshift和u、g、r、i、z等光度变量。

从物理解释角度看，alpha和delta不是直接描述天体光谱或光度性质的变量，因此不应将其作为核心解释特征。但从机器学习建模角度看，坐标变量可能隐含观测区域、采样机制或数据收集过程中的分布差异。因此，当前阶段不应直接删除alpha和delta，而应在后续模型训练后结合特征重要性进一步判断其实际贡献。

---

## 6.分类变量分析

spectral_type和galaxy_population属于分类变量，不能直接输入大多数机器学习模型，需要先进行编码处理。对于树模型，可以使用Ordinal Encoding或One-Hot Encoding；对于线性模型，通常更适合使用One-Hot Encoding，以避免人为引入无意义的顺序关系。

这两个变量可能包含与天体物理属性相关的类别信息，因此后续建模时应保留。需要注意的是，分类变量的具体处理方式会影响模型表现，因此后续Baseline阶段应先采用稳定、可解释的编码方式，再根据模型表现进一步优化。

---

## 7.阶段性结论

综合当前EDA结果，可以得到以下阶段性结论：

1.训练集存在明显类别不均衡，GALAXY为多数类，STAR为少数类。后续模型评估不能只看accuracy，应重点关注balanced accuracy、macro F1-score和混淆矩阵。

2.redshift在三类目标变量之间差异明显，是目前观察到的最具判别力的数值变量之一。它对区分QSO、GALAXY和STAR具有重要作用，但不能单独作为分类规则。

3.u、g、r、i、z等光度变量在不同类别之间存在明显分布差异，对分类任务具有较强信息含量。后续应在原始光度变量基础上进一步构造颜色指数特征。

4.alpha和delta作为坐标变量，单变量区分能力相对有限，但可能隐含观测区域或采样机制信息，因此当前阶段暂时保留，不直接删除。

5.spectral_type和galaxy_population作为分类特征，应在后续建模中进行编码处理，并纳入Baseline模型。

---

## 8.对后续建模的启示

基于EDA结果，后续Baseline模型应采用以下策略：

1.使用分层抽样划分训练集和验证集，确保训练集与验证集中各类别比例基本一致；
2.除accuracy外，同时使用balanced accuracy、macro F1-score、classification report和confusion matrix评价模型；
3.优先纳入redshift、u、g、r、i、z、alpha、delta、spectral_type和galaxy_population等原始特征；
4.构造u_g、g_r、r_i、i_z等颜色指数特征，增强模型对不同波段相对差异的刻画能力；
5.先建立Random Forest或Extra Trees等树模型作为Baseline，再根据结果考虑LightGBM、CatBoost或其他模型；
6.暂时不直接使用SMOTE等过采样方法，因为天文观测变量具有实际物理含义，简单合成样本可能产生物理上不合理的数据点。

因此，下一阶段应进入Baseline建模，重点验证EDA阶段得到的判断是否能在模型特征重要性、分类报告和混淆矩阵中得到支持。
